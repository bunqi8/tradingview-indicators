# TradingView Custom Indicators

A curated collection of PineJS custom indicators ported for the TradingView Charting Library.

## Indicators (`indicators/`)

This repository contains 16 custom indicators ready for real-time charting:

1. **Liquidity Swings** (`LiquiditySwings.js`)
2. **MACD Ultimate MTF** (`MACD.js`)
3. **Market Structure Break & Order Blocks** (`MSB-OB.js`)
4. **Market Bottom Vix Fix** (`MarketBottom.js`)
5. **Smart Money Breakout Channels** (`SmartMoneyBreakoutChannels.js`)
6. **Smart Money Concepts** (`SmartMoneyConcepts.js`)
7. **Squeeze Momentum Indicator** (`SqueezeMomentum.js`)
8. **SuperTrend AI Clustering** (`SuperTrendAI.js`)
9. **Support & Resistance Levels with Breaks** (`SupportAndResistanceLevelsWithBreaks.js`)
10. **Support Resistance Channels** (`SupportResistanceChannels.js`)
11. **Trend Range Detector** (`TrendRangeDetector.js`)
12. **Trendlines with Breaks** (`TrendlinesWithBreaks.js`)
13. **UT Bot Alerts** (`UTBotAlerts.js`)
14. **CM Ultimate MA MTF V2** (`UltimateMA.js`)
15. **WaveTrend LazyBear** (`WaveTrend.js`)
16. **Zigzag Trend / Divergence Detector** (`ZigzagTrendDivergenceDetector.js`)

## Usage

This repository is publicly available and integrated by default into the TradingView Charting application. No API token is required.
